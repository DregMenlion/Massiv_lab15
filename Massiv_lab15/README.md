# Индивидуальное задание

## Вариант 16

Ввести массив из `n` целых чисел и найти произведение порядковых номеров положительных элементов.

Программа проверяет каждый элемент. Если он больше нуля, умножает результат на его номер. Номера считаются с 1. Если положительных чисел нет, выводится сообщение об этом.

Например, в массиве `-4, 7, 0, 2, -6, 5` положительные числа стоят на местах 2, 4 и 6. Ответ: `2 * 4 * 6 = 48`.
